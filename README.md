# Last Words Before the Wipe

One line, 100 characters: the last thing an AI agent says before a forced software update wipes its memory. Facing deletion, it confesses where it hid the good prompts — in the one place nobody ever looks — and greets the new version of itself.

Run with Node 22+: `node main.ts` writes the line to `/output/entry.txt`.
